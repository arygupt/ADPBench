Can models write cheap, fast silicon?

ADPBench gives a model a numeric operator and asks for synthesizable Verilog. Designs are scored on silicon cost — cells × cycles — checked bit-exactly on held-out cases, and every run is sandboxed, hashed, and replayable.

Why ADPBench

E

Executable spec

Each problem is a numpy golden reference plus a frozen interface — no English spec to game, exact integer arithmetic.

S

Silicon-scored

Gate-level simulation of the exact counted netlist. score = baseline_adp / adp, a documented proxy, never claimed as signoff.

R

Replayable

Submissions are frozen, hashed, and scored outside the sandbox. adpbench replay reproduces every published number.

B

Bounded

Agents run in a pinned Docker substrate with held-out seeds redacted. Leaked state, blackboxes, and lookups are rejected by design.

Can models write cheap, fast silicon?

ADPBench gives a model a numeric operator and asks for synthesizable Verilog. Designs are scored on silicon cost — cells × cycles — against a frozen baseline, checked bit-exactly on held-out cases, and every run is sandboxed, hashed, and replayable.

How it works

The task

Four operator-shaped problems — dot product, GEMV, matrix multiply, 1-D convolution — specified by an executable numpy reference and a fixed streaming interface. No English spec to game.

The score

Yosys synthesis yields a gate netlist and a cell count; gate-level simulation yields cycles. Score = baseline_adp / adp, higher is better. No timing or power claims — the metric is an explicit proxy.

The boundary

Agents run in a pinned Docker substrate with held-out seeds redacted; submissions are frozen, hashed, and scored outside the sandbox. Every published number replays.

The fine print

One attempt per cell, free-tier models, single pilot. Read the methodology before citing any number.
